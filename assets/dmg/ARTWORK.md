# Cube Club installer artwork

`installer-background.png` is the original generated background, 1536 × 1024 pixels. It was created using the built-in image generation tool, with the existing `assets/AppIcon.iconset/icon_512x512.png` as a style/character reference. No CLI image-generation fallback was used.

The installer presents it at 800 × 533 points in an 800 × 593 Finder window, allowing space for window chrome. `scripts/prepare-dmg-background.swift` preserves all source pixels and writes a TIFF with the corresponding resolution metadata so Finder uses the intended size on Retina and ordinary displays. The real app and Applications shortcut are overlaid by Finder, not painted into the picture. Their locations are recorded in `scripts/dmg-layout.json`.

## Generation prompt

Use case: illustration-story / installer graphic. Create the FINISHED custom background artwork for a macOS drag-to-install disk image for Cube Club, a warm, carefully designed Rubik's cube teaching app for an eight-year-old. Reference image: the attached existing Cube Club app icon, for palette and friendly cube character identity only; do not place the app icon itself in the artwork. Landscape 3:2 composition, ideally 1536 × 1024 pixels. A premium children's creative workshop feeling: soft ivory paper (#f8f8f2), forest green (#233f37), muted mint, butter yellow, little peach and lavender details. Light fine paper texture, restrained flat illustration and playful clean rounded typography, generous empty space, impeccable readability. Top center headline exact text 'Cube Club' with small decorative sparkle; below it exact text 'A little cube magic. A lot of discovery.' Then centered at about 30% image height, exact instruction 'Drag Cube Club to Applications to get started.' The main installation row is at 57% image height: two EMPTY very pale rounded square landing areas centered at 28% width and 72% width, each about 20% of image width and 29% height, with a simple graceful forest-green arrow pointing right between them. These empty landing areas will hold real Finder icons after installation packaging: do NOT draw any app icon, folder icon, cube, or text inside these landing areas or within 90 pixels below them. Maintain complete uncluttered space for native Finder file labels below each area. Add one charming SMALL smiling 3×3 cube character in the lower-right corner, distinct from a square app icon, using the reference character's yellow top, white face and mint side, tiny waving arm, a few restrained star doodles, all contained outside the icon landing areas and their labels. Bottom center at 93% height exact text 'Small steps. Big discoveries.' A delicate curved green line or tiny dotted trail can decorate lower-left margin. No window chrome, no buttons, no watermarks, no other text, no extra folders. This is the actual flat background asset, not a screenshot or a mockup of a computer screen.

The final artwork was visually inspected. Native icon coordinates were adjusted to the generated landing areas; generated decoration also includes plants, books, and notes around the margins.
